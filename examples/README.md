# Examples

Copy one of these to `tower.toml` and edit.

| File | Adapter | Use |
|---|---|---|
| `tower.dsh.toml` | DSH sessions | **primary**: long-lived role sessions |
| `tower.cli.toml` | `claude -p` / `codex exec` | you already run agent CLIs |
| `tower.openai.toml` | OpenAI-compatible API | hosted model, no local agent |
